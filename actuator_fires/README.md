## 2. Hardware Wiring & GPIO Actuation
- **Control Interface:** Raspberry Pi 5 40-Pin Header (RP1 I/O Controller)
- **GPIO Pin 17:** Relay module triggering 24V DC solenoid diverter
- **GPIO Pin 27:** High-intensity Pass/Fail indicator LED
- **GPIO Pin 22:** Conveyor safety interlock line
